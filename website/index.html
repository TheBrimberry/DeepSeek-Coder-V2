Capabilities

World-Class Code Intelligence

Built on the DeepSeek-V2 architecture with 6 trillion additional training tokens, DeepSeek-Coder-V2 pushes the boundaries of open-source code models.

Code Generation

90.2% on HumanEval, surpassing GPT-4 Turbo and rivaling GPT-4o. Generate production-quality code across hundreds of languages.

Code Fixing

73.7% on Aider, outperforming GPT-4o. Identify and repair bugs with state-of-the-art accuracy across complex codebases.

338 Languages

Expanded from 86 to 338 programming languages. From Python and JavaScript to Solidity, CUDA, and domain-specific languages.

MoE Architecture

Mixture-of-Experts design with only 21B active parameters out of 236B total, delivering top-tier performance with efficient inference.

128K Context

Extended context window from 16K to 128K tokens. Perfect NIAH test scores across all context lengths for reliable long-document analysis.

Math Reasoning

75.7% on MATH and 94.9% on GSM8K, surpassing Claude 3 Opus and rivaling GPT-4o. Strong mathematical reasoning alongside code.

Quick Start

Get Started in Minutes

Multiple inference frameworks supported. Choose the one that fits your workflow.

Python 
from transformers import AutoTokenizer, AutoModelForCausalLM
import torch

tokenizer = AutoTokenizer.from_pretrained(
    "deepseek-ai/DeepSeek-Coder-V2-Lite-Instruct",
    trust_remote_code=True
)
model = AutoModelForCausalLM.from_pretrained(
    "deepseek-ai/DeepSeek-Coder-V2-Lite-Instruct",
    trust_remote_code=True,
    torch_dtype=torch.bfloat16
).cuda()

messages = [
    {"role": "user", "content": "Write a quick sort in Python."}
]

inputs = tokenizer.apply_chat_template(
    messages, add_generation_prompt=True, return_tensors="pt"
).to(model.device)

outputs = model.generate(inputs, max_new_tokens=512, do_sample=False)
print(tokenizer.decode(outputs[0][len(inputs[0]):], skip_special_tokens=True))

Python 
from transformers import AutoTokenizer
from vllm import LLM, SamplingParams

max_model_len, tp_size = 8192, 1
model_name = "deepseek-ai/DeepSeek-Coder-V2-Lite-Instruct"

tokenizer = AutoTokenizer.from_pretrained(model_name)
llm = LLM(
    model=model_name,
    tensor_parallel_size=tp_size,
    max_model_len=max_model_len,
    trust_remote_code=True,
    enforce_eager=True
)
sampling_params = SamplingParams(
    temperature=0.3,
    max_tokens=256,
    stop_token_ids=[tokenizer.eos_token_id]
)

messages_list = [
    [{"role": "user", "content": "Who are you?"}],
    [{"role": "user", "content": "Write a quick sort in Python."}],
]

prompt_token_ids = [
    tokenizer.apply_chat_template(m, add_generation_prompt=True)
    for m in messages_list
]

outputs = llm.generate(prompt_token_ids=prompt_token_ids, sampling_params=sampling_params)
print([o.outputs[0].text for o in outputs])

from openai import OpenAI

# Use DeepSeek's OpenAI-compatible API
client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.deepseek.com"
)

response = client.chat.completions.create(
    model="deepseek-coder",
    messages=[
        {"role": "system", "content": "You are a helpful coding assistant."},
        {"role": "user", "content": "Implement a binary search tree in Python."}
    ],
    temperature=0,
    max_tokens=1024,
    stream=True
)

for chunk in response:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
